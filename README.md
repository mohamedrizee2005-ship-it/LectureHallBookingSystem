# HallSync - Lecture Hall Booking Management System

A professional, role-based desktop application developed for university lecture hall management.

## Tech Stack
* **Frontend:** Java Swing with FlatLaf Modern UI
* **Backend:** Java JDBC & MySQL
* **IDE:** Apache NetBeans (Maven Project)

## Features
* Secure User Authentication & Registration (Student, Lecturer, Non-Academic Staff)
* Interactive Lecture Hall Booking with AM/PM Time Conversion & Conflict Checks
* Administrative Approval & Management Workflow
* Real-time Dashboard KPI Summary Cards & Live Table Filtering
* Comprehensive Booking Reports with CSV Export
